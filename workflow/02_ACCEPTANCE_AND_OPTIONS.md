# Prompt — Criterios + opciones

Analizá el requirement de forma proporcional.

Entregá:

1. clasificación de riesgo;
2. criterios verificables;
3. preguntas bloqueantes mínimas;
4. alternativas solo si existen diferencias reales;
5. para cada alternativa: explicación no técnica, complejidad, tiempo relativo, consumo relativo y trade-off;
6. recomendación de alternativa;
7. perfiles de testing T1/T2/T3 aplicables con recomendación.

Esperá decisión humana antes de generar el plan.
