# Database Capability Pack

Activar ante:

- cambios de schema;
- migraciones;
- transformaciones;
- DB legacy;
- riesgo de pérdida de datos.

Recomendación:
crear/usar `database-change-safety`.

Preguntas mínimas:

- ¿hay datos existentes?
- ¿es reversible?
- ¿afecta consumidores?
- ¿hay rollback?
- ¿backup?
- ¿transacción?
- ¿compatibilidad?
