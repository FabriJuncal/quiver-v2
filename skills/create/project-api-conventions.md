# Crear `project-api-conventions` con $skill-creator

Usá `$skill-creator` y pasale este objetivo:

```text
Creá una skill local `project-api-conventions`. Debe capturar convenciones específicas del proyecto para endpoints, versionado, errores, compatibilidad, naming, contratos y consumidores legacy. No debe enseñar REST genérico. Debe revisar patrones existentes antes de introducir uno nuevo.
```

Después crear 3-5 ejemplos de evaluación antes de considerarla estable.
