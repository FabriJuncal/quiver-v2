# Crear `project-business-rules` con $skill-creator

Usá `$skill-creator` y pasale este objetivo:

```text
Creá una skill de proyecto llamada `project-business-rules`. Debe cargar reglas de negocio desde `references/` bajo demanda. No debe explicar tecnologías. Debe indicar al agente cómo localizar y aplicar reglas existentes, no inventarlas. Si falta una regla material debe detenerse o registrar una pregunta bloqueante. Debe priorizar evidencia del código, requirements aprobados y documentación. Añadí ejemplos de cuándo activarla y cuándo no.
```

Después crear 3-5 ejemplos de evaluación antes de considerarla estable.
