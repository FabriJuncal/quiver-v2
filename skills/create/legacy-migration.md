# Crear `legacy-migration` con $skill-creator

Usá `$skill-creator` y pasale este objetivo:

```text
Creá una skill `legacy-migration` orientada a migrar comportamiento sin perder paridad. Flujo mínimo: localizar implementación legacy, casos de uso, validaciones, requests, responses, reglas, dependencias, diferencias con solución nueva, matriz de compatibilidad, criterios de aceptación, implementación y regresión dirigida. No rediseñar por defecto ni aprovechar para refactorizar fuera de alcance.
```

Después crear 3-5 ejemplos de evaluación antes de considerarla estable.
