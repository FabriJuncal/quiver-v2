# Crear `project-database-rules` con $skill-creator

Usá `$skill-creator` y pasale este objetivo:

```text
Creá una skill local `project-database-rules`. Debe capturar convenciones reales del proyecto: tablas, SPs, migrations, naming, transacciones, acceso a datos y restricciones. No debe inventar reglas ni reemplazar `database-change-safety`.
```

Después crear 3-5 ejemplos de evaluación antes de considerarla estable.
