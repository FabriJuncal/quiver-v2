# Crear `database-change-safety` con $skill-creator

Usá `$skill-creator` y pasale este objetivo:

```text
Creá una skill `database-change-safety` enfocada en seguridad de cambios de datos/schema. Antes de ejecutar debe verificar pérdida potencial, compatibilidad, consumidores, reversibilidad, backup, transacciones, locks, migración de datos, rollback y pruebas. Debe adaptarse al motor del proyecto; no asumir Prisma/TypeORM. Debe soportar SQL Server, PostgreSQL, MySQL y estrategias manuales.
```

Después crear 3-5 ejemplos de evaluación antes de considerarla estable.
