# Crear `mobile-release` con $skill-creator

Usá `$skill-creator` y pasale este objetivo:

```text
Creá una skill `mobile-release` para proyectos móviles. Debe cargar referencias separadas para Android, iOS, Capacitor/PWA/OTA cuando correspondan. Debe verificar versiones, builds, signing, environment, stores, rollback y compatibilidad. No activar para proyectos no móviles.
```

Después crear 3-5 ejemplos de evaluación antes de considerarla estable.
