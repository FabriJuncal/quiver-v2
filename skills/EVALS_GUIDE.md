# Guía rápida para evaluar skills

Una skill no está “bien” solo porque su texto suena profesional.

Para cada skill propia:

1. preparar 3-5 casos reales;
2. ejecutar con y sin skill;
3. medir errores, retrabajo, tokens, preguntas y tiempo;
4. revisar si se activa en tareas equivocadas;
5. reducir instrucciones innecesarias;
6. mantener solo si aporta valor medible.
