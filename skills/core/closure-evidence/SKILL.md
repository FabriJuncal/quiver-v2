# Closure Evidence

Evidence before claims.

Before saying:

- done;
- fixed;
- tests pass;
- build succeeds;

identify the command/check that proves it.

Run it when possible.

Read actual output/status.

Record:

- criteria verified;
- tests executed;
- result;
- deviations;
- pending;
- residual risk.

For the full workflow, update `06_CLOSURE.md`, requirement state and project state. For compact N0/N1 work, record the same necessary evidence in its existing state instead of creating the full document set. Apply `../../../workflow/09_CLOSURE.md` to hand off the next authorized work or identify the exact remaining decision.

Confidence is not evidence.

## AI execution evidence

When available, record profiles actually used, escalations/downgrades and retries/rework.
Do not invent token or cost data.
