# Ejemplo — SaaS nuevo

Primero discovery, después capacidades.

```yaml
project:
  mode: new
  type: saas
business:
  market: argentina-latam
```

Capacidades posibles:

```text
UI
Auth
Database
Multi-tenant
Billing
Emails
Deployment
```

Elegir proveedores solo después de confirmar mercado, complejidad y restricciones.
El starter SaaS es opcional y separado de la Factory.
