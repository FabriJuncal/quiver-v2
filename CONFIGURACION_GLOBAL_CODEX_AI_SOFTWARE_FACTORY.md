# Configuración global de Codex

La guía vigente es [Configuración de Codex](docs/guides/CONFIGURACION_CODEX.md). Para instalar desde cero, seguir [Quick Start](QUICK_START.md).

El instalador administra únicamente su bloque y enlaces de skills core. No copiar manuales completos a AGENTS ni usar rutas de skills de versiones anteriores. El manual anterior se conserva en el historial Git, pero no es la fuente de instrucciones actuales.

Si existe AGENTS.override.md global, resolver explícitamente su prioridad antes de instalar: Factory no modifica ese archivo. El diagnóstico está en [Troubleshooting](docs/troubleshooting/INSTALLATION.md).
