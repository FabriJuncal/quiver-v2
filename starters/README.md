# Starters

Los starters no son el core de AI Software Factory.

Recomendación:

- Factory = repositorio instalable una vez;
- SaaS starter = repositorio GitHub Template separado.

Esto permite:

- utilizar Factory en cualquier stack;
- evolucionar el starter sin acoplarlo al workflow;
- no imponer tecnologías a proyectos existentes.

Un futuro `ai-saas-starter` puede comenzar mínimo:

- Next.js/TypeScript;
- UI base;
- testing/lint;
- Factory project layer;

y agregar auth/billing/database por capacidades, no todas por defecto.
