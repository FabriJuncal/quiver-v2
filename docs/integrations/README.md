# Integraciones opcionales

AI Software Factory funciona sin MCPs externos.

Agregar un MCP solo si:

- elimina trabajo manual frecuente;
- permite verificar algo real;
- da acceso a una fuente externa necesaria.

Ejemplos:

- GitHub → repos/issues/PRs;
- DB/Supabase → schema/datos;
- Browser DevTools → runtime UI;
- Figma → diseños;
- Stripe → billing;
- Vercel → deployments/logs.

**Skill = cómo trabajar.**

**MCP/Tool = capacidad para consultar/actuar.**
