# AI Software Factory v2.3.0-rc.2 — Supervised Delegation Preview

**Prerelease/preview offline.** Mantiene la delegación inactiva: no presentar como
multiagente operativo ni como piloto vivo aprobado.

## Cambios desde rc.1

- Routing `routing-v1` considera riesgo, verificabilidad y costo/límite de comprobación.
- Ruta rápida hereda estrategia vigente por fase y evita clasificación, contexto y gates repetidos.
- Antes de escalar distingue fallos de entorno, evidencia/contexto faltante, decisiones
  de producto y fallos reales de análisis.
- Reintentos requieren evidencia o enfoque diferente y una comprobación capaz de refutarlo.
- Planning, ejecución y review exigen una decisión breve o referencia vigente; las
  excepciones N0/consultas evitan burocracia artificial.
- Catálogo central conserva mappings y perfiles; no se agregaron modelos, controladores,
  telemetría, llamadas pagas ni selección invisible del runtime.

## Preview offline preservada

Conserva contratos de delegación guiada/supervisada, contexto mínimo, auditoría de
copias, estados de intento, aceptación del coordinador, CE-v1 y ejemplos sintéticos.
La propuesta de ayudante permanece deshabilitada y el validador continúa fail-closed.

## Límite para activar el ayudante

RC-F02 sigue abierto: no se verificó que el runtime aplicado al hijo impida recursión,
acciones externas mutantes y permisos/herramientas fuera del contrato, ni su detención
efectiva. **Piloto NOT RUN; cero intentos consumidos.** Publicar esta preview no habilita
delegación y no prueba una integración viva.
