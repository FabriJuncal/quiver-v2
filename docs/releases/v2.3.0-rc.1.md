# AI Software Factory v2.3.0-rc.1 — Supervised Delegation Preview

**Candidata local. Sin tag, push ni publicación.** No presentar como multiagente
operativo: incluye preparación e integración inactiva, no piloto vivo aprobado.

## Incluido

- Runtime Guardrails y model routing existentes preservados.
- Contratos de delegación guiada/supervisada, contexto mínimo, auditoría de copias,
  estados de intento, aceptación por coordinador y ejemplos sintéticos.
- Propuesta genérica de coordinador/ayudante, deshabilitada; validación offline.
- Versionado RC, guías de instalación/actualización y paquete sin trials locales.

## Bloqueo para activar el ayudante

La sesión evaluada no permite vincular el rol/configuración al spawn ni verificar
herramientas efectivas sin recursión y sin acciones externas mutantes. La prueba
de sandbox de comandos no prueba herencia al ayudante. Un intento no debe lanzarse
para descubrir luego sus permisos. **Piloto NOT RUN; cero intentos consumidos.**

Ver [integración mínima y siguiente paso](../guides/ASSISTANT_INTEGRATION.md).
No instalar otro runtime ni cambiar permisos habituales como parte de esta candidata.

## Instalar o actualizar

- Primera instalación: [QUICK_START](../../QUICK_START.md), usando el paquete local.
- Ya instalado: [upgrade paso a paso](../guides/UPGRADE_2_2_2_TO_2_3_0.md), incluye
  configuración opcional de perfiles y prompt exacto para proyectos existentes.
- Ejemplos sin agentes: [v1](../../examples/guided-delegation/README.md) y
  [supervisado v2](../../examples/supervised-multiagent/README.md).

Instalar no activa delegación ni modifica config.toml. Los perfiles cambian la
configuración solicitada, no prueban disponibilidad o modelo realmente activo.

## Antes de cualquier publicación

Revisión y aprobación explícita del alcance (preview offline o funcionalidad viva
verificada), diff completo y resultados del artefacto final. CI remota macOS/Linux
queda pendiente hasta autorizar push; no equiparar tests locales con CI ejecutada.
Nunca publicar esta candidata como cumplimiento de un piloto que no se ejecutó.
