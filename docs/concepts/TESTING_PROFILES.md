# Testing proporcional

AI Software Factory utiliza tres perfiles comprensibles.

## T1 — Esencial dirigido

Verificar el cambio y sus riesgos concretos con el mínimo suficiente.

No significa "sin tests".

## T2 — Reforzado

Agrega casos límite y validación de dependencias afectadas.

Suele ser una buena opción para cambios funcionales de riesgo medio.

## T3 — Alta garantía

Amplía escenarios negativos, integración, recuperación o revisión independiente cuando el riesgo lo justifica.

No significa "ejecutar todas las categorías de testing".

## Regla

El mínimo está determinado por el riesgo.

Una modificación de autorización puede necesitar más validación en T1 que un cambio visual en T2.

No aumentar el perfil silenciosamente.
