# Proyecto nuevo vs. proyecto existente

## Proyecto nuevo

La Factory puede recomendar defaults simples.

Flujo:

```text
Discovery
→ Product
→ Capabilities
→ Technical options
→ Decision
→ Backlog
→ Requirements
→ Implementation
```

## Proyecto existente

Regla:

> Integrar antes que migrar.

Primero:

```text
Project Discovery
→ PROJECT_PROFILE
→ CAPABILITY_MAP
→ PROJECT_STATE
```

Clasificación:

- `KEEP`
- `ADD`
- `WRAP`
- `IMPROVE`
- `REPLACE_LATER`
- `IGNORE`

No recomendar una migración porque el stack no coincida con los defaults de Factory.
