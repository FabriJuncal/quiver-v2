# Argentina, mercado y proveedores

AI Software Factory no debe asumir que un proveedor está disponible solamente porque es popular internacionalmente.

## Pagos

Antes de elegir:

1. país/entidad legal del negocio;
2. mercado objetivo;
3. monedas;
4. impuestos/compliance;
5. necesidad de Merchant of Record;
6. proveedor ya existente.

Ejemplos posibles:

- Mercado Pago para ciertos productos orientados a Argentina;
- Merchant of Record para productos globales cuando convenga;
- Stripe cuando la entidad y país sean compatibles.

**Verificar siempre el soporte oficial vigente antes de implementar.**

No crear una estructura societaria extranjera solamente porque un starter la presupone.

## Infraestructura

Elegir región según:

- usuarios;
- base de datos;
- backend;
- latencia.

No según dónde vive el desarrollador exclusivamente.

## Proyectos existentes

Mantener proveedores actuales cuando funcionan y no existe un motivo concreto para migrarlos.

> Esta guía es técnica/producto y no reemplaza asesoramiento fiscal o legal.
