# MCP y herramientas

## Diferencia

```text
Skill = procedimiento
MCP/Tool = acceso a algo externo
```

## Ejemplos

```text
api-and-interface-design + GitHub
Impeccable + Browser DevTools
DB safety + DB MCP
billing rules + Stripe/MercadoPago
project-management + Linear/GitHub Issues
```

## Regla

Agregar un MCP solo si:

- elimina trabajo manual frecuente;
- permite verificar datos externos;
- evita suposiciones;
- se usará de verdad.

No instalar diez MCPs “por las dudas”.
