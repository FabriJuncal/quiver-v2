# AI Software Factory v2

Sistema de trabajo para crear proyectos nuevos y evolucionar proyectos existentes con IA sin obligar a usar un stack, modelo de negocio o arquitectura determinados.

## Objetivo

- Mantener el repositorio como fuente de verdad.
- Reducir dependencia del chat.
- Planificar y desarrollar con proporcionalidad.
- Reutilizar procedimientos de IA sin cargar contexto innecesario.
- Adaptarse a proyectos nuevos o existentes.
- Permitir SaaS, apps web/móviles, APIs, sistemas internos, e-commerce, automatizaciones, IA, legacy y otros modelos.
- Priorizar simplicidad, reversibilidad y costo operativo bajo.

## Empezar

1. Leer `00_GUIA_PARA_COMENZAR.md`.
2. Leer `01_EXPLICACION_COMPLETA_DEL_PROYECTO.md`.
3. Elegir `NEW PROJECT` o `EXISTING PROJECT`.
4. Inicializar `PROJECT_PROFILE.md`, `PROJECT_STATE.md` y `CAPABILITY_MAP.md`.
5. Trabajar cada requerimiento dentro de `docs/requirements/<ticket>/`.

## Regla central

> La Factory se adapta al proyecto. El proyecto no se adapta a la Factory.
